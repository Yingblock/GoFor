# DESIGN — 稳定设计

> 范围：跨阶段的稳定设计；阶段实现细节在 `docs/Phase-note/`；当前状态在 `docs/STATE.md`。

## 1 纸张优先设计律（原 §8）

> 纸是主输入端，不是输出端。每日闭环在纸上完成，屏幕只做「拍照回填」和「每周收银」。

| # | 设计律 | 落点 |
|---|---|---|
| 1 | 每日闭环在纸上：打勾、写 1–3 行起止时间 | 回家 1 次拍照（≤30 秒）+ 确认（≤1 分钟） |
| 2 | 屏幕功能要么耗时少，要么非每日必须 | 费时的排程/复杂设置砍掉或推到周末 |
| 3 | 纸上必须能表达「量」，不能只有勾 | 用时间登记写起止，产出 `StudySession`（§6） |
| 4 | 模板自解释：不看 App 也知道怎么填 | 纸丢了有手动补录兜底 |
| 5 | 容忍纸的物理现实：折叠、脏污、倾斜、透写背面 | 扫描链路按低对比度设计（§5） |
| 6 | 省纸：学生不会带一叠纸 | 按 A5 一天 / A4 一周设计版式；`config.print.paper` 默认 A4 |
| 7 | 每周一次屏幕大循环：扫描回填 → 周报 → 打印下周 | 唯一允许「重」的操作 |

| 频率 | 在哪 | 做什么 |
|---|---|---|
| 每段学习 | 纸/App | 纸上写起止；用 App 时番茄钟自动记录 |
| 每天 | 纸 | 打勾、写 1–3 个数字 |
| 每天回家 | 手机 | 拍 1 张照片 + 确认 |
| 每周周末 | 电脑/手机 | 扫描回填全部、看周报、打印下周 |
| 每月 | 电脑 | 复盘、调整模板 |

任何新功能先回答「它落在上面哪一行」；落在「每天都要在屏幕上操作」就有问题。

## 2 信息架构与导航（原 §13）

两套记法互不干扰，避免「P1·M1」既像开发阶段又像产品部分：

| 记法 | 含义 | 例子 |
|---|---|---|
| 离线 / 在线 + M1–M3 | 产品部分 | `离线·M2` = 记录模块 |
| P0–P8 | 开发阶段（见 `docs/ROADMAP.md`） | `P1` = 离线核心闭环 |

左侧工具栏按产品部分分组；看到 P 是开发阶段，看到「离线/在线」是产品部分。

| 编码 | 条目 |
|---|---|
| 离线·M1 工具 | 番茄钟、环境清单、单词库；笔记本、画板、电子产品锁定（占位） |
| 离线·M2 记录 | 作业清单、课程表、每日打卡、扫描回填、三格自评、自我周报；使用时长（占位） |
| 离线·M3 导出 | 打印 checklist、模板与校准页、数据与备份、插件与扩展 |
| 在线·M1 好友 | 好友与状态（占位） |
| 在线·M2 云存档 | 存档与分享（占位） |
| 在线·M3 心理支持 | 自助工具箱、情绪日记 |
| 插件 | 未声明已知分组的插件页面（兜底组） |

1. 左侧是唯一一级导航，不用顶部横向导航、不用底部 Tab。
2. 点分组标题手风琴展开/收起，不跳页；点条目切主区域。
3. 首页永远独立入口（左上角标题或 📷 左侧 home 位）。
4. 未进入阶段的条目仍显示但置灰，点击提示「阶段 Pn，尚未开始」。
5. 窄屏（<768px）侧栏收成抽屉；桌面可折叠成 56px 图标列（`localStorage` + `Ctrl/⌘+B`），折叠态悬停显示名字。
6. 插件页面按 `manifest.group` 插入分组，未知组进「插件」兜底组；组内用 `order` 排序，插件禁用即消失。

被移出的自创功能：**专注格（番茄格）**已从首页与默认模板撤回，记入 `docs/LATER.md`，恢复需用户明确批准；时间登记保留（用户提出）。

首页自上而下：顶部两个主行动（拍照录入、打印 checklist）→ 今日课表 → 打卡提示 → 统计 → 今日记录 → 任务提示。
统计取数必须真实：没数据显示 0 并注明原因（如「番茄钟尚未开始」），不编数字。

## 3 配置体系（原 §10）

| 层 | 位置 | 谁改 | 例子 |
|---|---|---|---|
| 默认值 | `packages/core/src/config/defaults.ts` | 开发者 | 默认 A4、默认 4 个番茄后长休息 |
| 用户配置 | Dexie，UI 可改 | 用户 | 纸张尺寸、课时、墨迹阈值 |
| 导出 JSON | 随备份/分享 | 用户 | 换设备、给同学抄配置 |

- 任何来源的配置都过 zod schema（`parseConfig` / `mergeConfig`），默认值也不例外。
- 判断标准：**现实世界会变 → 配置化；产品设计决定 → 不配置化**。
- 配置项超过约 40 条说明设计失控；新增前先问「能不能从已有东西推导」。

| 应配置化 | 不配置化 |
|---|---|
| 课时长度、作息表、科目列表、教材目录 | 交互流程、数据模型、同步协议 |
| 纸张尺寸、模板选择 | 视觉风格（配色、间距） |
| 墨迹阈值、识别灵敏度 | 快捷键默认值（可调但不做 UI） |
| 番茄时长与休息节奏 | 纸面区块种类 |

**派生优先于手填**：能从课表/作息表推导的，绝不让用户手填。`periods` 只在配置根目录存一份：

```
Periods（ICS / 手工 / 拍照导入）
  ├→ 一节课多少分钟 → focus.unit（专注格已撤回，见 §6）
  ├→ 默认番茄时长 → 番茄钟
  ├→ 限时套卷的分段提醒
  └→ 打印模板的课表区块与时间轴
```

`schemaVersion` 每次破坏性改版 +1 并写迁移函数；配置迁移失败 = App 打不开，比数据迁移失败更致命。

## 4 打印模板：可拼装的纸（原 §11）

`timeLog`（自主时间登记）、`ratingGrid`（1–N 自评勾选格）、`slots`（手写小格）都是普通 block：模板可以只放一个、几个或都不放，没有「默认方案」。专注格已撤回（§6）。

```jsonc
{ "id": "day-a5", "paper": "A5", "blocks": [
  { "id": "t", "kind": "title", "span": 12, "text": "", "align": "left" },
  { "id": "tk", "kind": "checkboxList", "span": 12, "bind": "tasks.today", "rows": 5, "showMeta": [] },
  { "id": "am", "kind": "timeLog", "span": 12, "dayPart": "morning", "rows": 1, "label": "上午" },
  { "id": "rt", "kind": "ratingGrid", "span": 12, "labels": ["睡眠", "心情", "专注"], "scale": 5 }
] }
```

`title` 的 `text` 留空，由 `materialize()` 在打印时填当天日期；模板里写死某天会让常量被误当今天。

版式模型是 **12 列网格 + 固定高度**，不用浮动布局或自由画布：纯算术、可单测、可复现，并能直接生成回填坐标。

1. 区块按声明顺序纵向流式排列，本行放不下就换行。
2. `span` 1–12 控制横向占比（12 整行、6 半行、4 三分之一）。
3. 高度 = 内边距 + 行数 × 行高；**行数是显式参数**，数据多了缩字号或提示截断，不悄悄撑破版面。
4. 超出一页自动换页；`pageBreak` 强制换页；单块高于整页时明确丢弃并告警。
5. 实测：完整混合版约 201mm，A5 可用 194mm 装不下 → **完整版必须 A4，A5 只放精简版**；`fitsOnePage()` 会算出超出量。

模板编辑器分两期：v0 列表式（组件面板 → 纸张预览 → 属性 → 拖拽排序 → 溢出提示）；自由定位画布记入 `docs/LATER.md`，不进主路径。

必须提前解决的坑：

1. **内容长度可变**：`rows: 5` 但今天 9 项作业 → 只渲染前 5 项 + 「+4 项见 App」角标，或提示改行数；不做自动缩字号（手写空间不够，纸就废了）。
2. **打印校准页**：`calibration` 模板印近似 10mm 刻度 + 四角定位标，一次打印即可检查缩放、边距、定位点是否被裁。
3. **浏览器打印固定套路**：关闭页眉页脚、缩放 100%、勾选「背景图形」、`@page { size: <paper>; margin: 0 }`；写成一屏「打印前检查」。
4. **坐标随版式生成**：`normalizePlacement()` 产出 0–1 归一化矩形，编译期确定，与扫描分辨率/手机型号/拍摄角度无关。

定位点尺寸与位置是打印/扫描共享契约，采样窗必须与渲染对齐，详见 `docs/Phase-note/P2/print.md`。

## 5 纸的回流：坐标先验（原 §3 + §16.1–16.2 摘要，细节指向 Phase-note/P2/paper-loop.md）

**不做通用 OCR**：模板由本程序生成，精确知道每个格子的坐标，识别问题从「读懂手写」降级为「已知矩形里有没有墨」。纯像素运算、可完全离线，准确率由纸张摆放与透视矫正决定而不由字迹决定；代价是纸必须由本程序打印、拍照要大致正对纸。

三个不变量：打印时固化清单（回填时重算会把勾记到别人头上）、一律先进待确认（不把识别当事实）、只读已知矩形（不推断文字内容）。

读不了的手写区明确不做自动读取：时间登记与 `slots` 手写格留到 P4 OCR；要回填数值改用 `ratingGrid` 勾选格。链路、数据模型、失败与降级见 `docs/Phase-note/P2/paper-loop.md`。

## 6 时间记录：专注格与时间登记（原 §9）

两种机制都曾用于还原学习时长；**当前产品只用时间登记**，专注格已撤回（§2、`docs/LATER.md`）。下表保留对比，用来说明取舍。

| | 专注格（勾/涂，已撤回） | 时间登记（当前） |
|---|---|---|
| 每次操作 | 找到行划一笔 | 写 4 位数字 |
| 需要看钟 | 不需要 | 需要 |
| 能还原 | 时长、分科 | 时长、分科、几点学的 |
| 漏记恢复 | 事后补勾 | 只能估 |
| 版面前提 | 预印科目行 | 不需要 |

| 场景 | 机制 | 每日操作量 |
|---|---|---|
| 在校课时 | 课表预印；需要时长时用时间登记 | 0–2 笔 |
| 在家/自习 | 时间登记（做什么 + 起止），按上午/下午/晚上分栏 | 1–3 行 |
| 用 App 时 | 番茄钟自动记录 | 0 |

若恢复专注格（先经用户批准）：方块只是定位框，一划即可，不必涂满；在校时段由课表预印，默认全完成、只圈「这节没学」的例外；行 = 科目（或自习/作业/复习伪科目），格 = 一个专注单元（`focus.unit`，默认跟随作息表），状态只有有笔迹/无笔迹（不支持半格与颜色区分），`有笔迹格数 × resolveUnitMinutes(config)`。

两种来源共用同一结构，统计/周报/相关性只写一套：

```ts
interface StudySession {
  date: string;
  start: number;            // 当日第几分钟
  end: number;
  subjectId?: string;
  taskId?: string;
  source: 'paperTime' | 'paperGrid' | 'appTimer';
}
```

时间登记的歧义靠版面消除，不靠算法猜：纸面按上午/下午/晚上分栏，`dayPart` 写在栏标题。
解析在 `packages/core/src/paper/timeRange.ts`：支持 `19:30` / `1930` / `19.30` / `19点30分` / `19:30~20:15` / `19:30到20:15` / 跨零点 `23:30-0:30`，全角转半角；解析不出来明确失败进待确认，不瞎猜；只写开始时 `end = null`，由调用方套默认时长。

## 7 错题本、块文档与 SRS（原 §1、§6）

错题本不追求「把题全部 OCR 成文字」，而是**模拟扫描 + 混排文档**：能识别的变文字，不能识别的直接裁图排版。

```
拍照 → 边缘检测 + 透视矫正 → 光照均衡/去阴影 → 版面分析（分栏+行切分）
     → 逐行 OCR（文本, 置信度, bbox）→ 分派：
        高置信度且非公式 → TextBlock（可编辑）
        低置信度或公式/图表 → ImageBlock（原图裁剪，按原位还原）
     → 组装混排文档，渲染成「看起来像原卷」的页面
```

| 维度 | 全 OCR | 混排 |
|---|---|---|
| 数学公式 | 必须校对 LaTeX | 直接贴图，零校对 |
| 校对成本 | 与错误率成正比 | 只校「被转成文字」且置信度高的行 |
| 保真度 | 排版可能走形 | 100%（就是原图） |
| 实现难度 | 需公式识别 + 复杂重排 | 行级切分 + 两种 block |

- 切块粒度 = 行，不是字符；`ImageBlock` 保留低置信度猜测 `searchText`（不显示但参与搜索）。
- `ImageBlock` 存归一化 bbox + 原图裁剪，按原宽高比排布；多栏先降级为手动框选，不做全自动重排。
- 块可升级：`ImageBlock` 上「转 LaTeX / 转文字」按钮（BYOK provider），用户觉得值得再转。
- **错题本的题目块与笔记的块用同一套数据结构、同一个编辑器**；扫描 CV 管线与二维码回填共用 `packages/vision`。

边界：任何「做不好」的内容不降级为错误，降级为图片。

| 内容 | 现实效果 | 处理 |
|---|---|---|
| 印刷体中文题干 | ≈99% 字符准确 | 转文字 |
| 印刷体数学公式 | 通用 OCR 全废 | 直接贴图 |
| 双栏/多栏试卷 | 行序会串 | 手动框选区域 |
| 表格 | 基本不行 | 整块贴图 |
| 手写中文 | 60–85% | 默认贴图，可手动转文字 |
| 手写数学推导、几何图、电路图 | 很差/不识别 | 贴图 |

SRS 不自创调度算法：

| 方案 | 说明 |
|---|---|
| FSRS（推荐） | 公开算法里最先进，Anki 在用，有开源实现与参数拟合工具 |
| SM-2 变体 | 极简，20 行代码，效果够用，适合 P4 第一版 |
| 自创 | 会花两周调参，然后发现不如 SM-2 |

P4 先上 SM-2 变体，积累几百条复习日志后再换 FSRS 并拟合参数。复习项与番茄钟联动：「刷 15 分钟错题」就是一个特殊的番茄会话。OCR provider 见 §8。

## 8 OCR / AI 的边界（原 §1.3、§2）

OCR 与 AI 都是可替换 provider，不是核心依赖。契约在 `packages/plugin-api`：`OcrProvider { status(), recognize() }`、`AiProvider { status(), complete() }`，默认实现返回 `not-configured`；OCR 在 P4、AI 在 P8 接入，见 `docs/PLUGINS.md`。

低置信度不是实现缺陷，而是方案的设计出口——永远有地方可去（贴图 / 待确认 / 手动转写）。

生成式 AI 的失败模式必须知道：

| 失败模式 | 表现 |
|---|---|
| 幻觉推导 | 中间步骤算错但结论碰巧对 |
| 几何伪证 | 跳步、「显然成立」、循环论证 |
| 物理边界条件 | 单位、摩擦、理想化假设随手忽略 |
| 编造理由 | 选项对了，解释是编的 |
| 过度自信 | 语气肯定，用户无法分辨 |

缓解手段：让模型输出可验证形式（代数题给 `sympy` 可执行表达式，本地跑一遍；数值题多组代入）、多次采样投票（3 次不一致标「不确定」）、强制结构化输出 `{ keySteps[], finalAnswer, assumptions[], confidence }`、永远不说「标准答案」、提供「这条解析有错」反馈、同题同解析缓存。

成本与延迟：带图长推导单次几千到几万 token、延迟 10–60 秒 → 必须异步任务 + 流式输出 + 后台通知，不让用户盯着转圈；BYOK 让用户承担成本与「服务提供者」身份。

隐私：题目照片常带姓名/班级/学校 → 上传前可选自动裁剪，默认只上传裁剪块；明确提示「此图片将发送给 <服务商>」；key 本地加密，绝不进日志、同步、崩溃上报。

**不做任何门禁**：默认学生自觉，「先写思路才能看解析」只会增加摩擦（`docs/STANDARD.md` 第 11 条）。保留三件与准确性有关的事：标注「AI 参考解析，可能出错，请自行核对」、结构化 + `sympy` 校验 + 多次采样一致性、错误反馈按钮。AI 讲解永远不能是核心依赖，核心是「自己的错因标签 + 复习调度」。

书写引导用「功能性理由 + 物理手段」，不说教：提示印在纸上（`深色笔 · 不出框 · 不连笔 · 公式写大一点`）、用浅色格线约束版式、扫描结果页显示「本次识别率 82%，第 3–5 行按图片保留」。**不采集笔迹训练通用模型**（笔迹是敏感生物特征，未成年人更敏感），改做只服务本机的个性画像：勾选墨迹占比分布校准阈值、常错字的本地替换表、个人符号习惯、常用科目/章节排序。

危机识别不做，只保留静态「求助资源」页（热线列表 +「告诉一个可信任的成年人」），不做检测逻辑。

## 9 统计口径（原 §4）

**只采集一次，多处复用**：统计不额外打点。

| 数据 | 采集时机 | 复用 |
|---|---|---|
| 科目时长 | 番茄钟开始时选科目（本来就要选） | 结束时生成一条 `session` |
| 任务科目 | 任务绑定科目 | 自动推断，无需输入 |
| 补录 | 事后「快速补录」（5 秒点选时长+科目） | 一天 5–8 次点击，成本可接受 |
| 章节维度 | 错题的章节标签 | P4 自然得到，不单独打点 |

**知识点热力图做不到**：没有题库、标准标签体系与足够样本，如实改名。替代（只依赖自己的数据，不宣称科学性）：

| 替代 | 数据来源 | 价值 |
|---|---|---|
| 章节错题密度 | 错题章节标签 | 哪里错得多 |
| SRS 复习状态 | 调度参数与到期时间（SM-2 / FSRS） | 哪些卡快忘了 |
| 复习正确率趋势 | 四档评级 | 真实进步曲线 |
| 标签共现 | 错因标签组合 | 「我总是审题错」 |

标签体系的唯一可用骨架 = 教材目录（人教版/北师大版章节树），让用户导入/编辑一棵树即可。对外叫「**我的错题分布**」，不叫「知识图谱/学情诊断」；不宣称科学性反而最科学。

打卡与学习记录**不互相推导**：

| | 打卡 | 学习记录 |
|---|---|---|
| 语义 | 我承诺做某件事并对自己负责 | 我实际花了多少时间 |
| 数据源 | 手动勾选 `habitLogs` | 番茄钟 / 纸面登记 `sessions` |
| 失败方式 | 忘勾 → 数字偏低（诚实） | 忘记 → 数字偏低（诚实） |

首页「连续学习」按 `sessions` 算，打卡连续天数按 `habitLogs` 算，两者互不引用。

睡眠/心情/专注的相关性：每天睡前 3 个滑块（约 10 秒），或每个番茄结束 1 击打专注度；上学日可用 `slots` 区块手写，P2 起需要扫码回填的数值改用 `ratingGrid` 勾选格。分析用分箱均值 + Spearman 相关，不需要机器学习。

## 10 平台矩阵、私服与对象存储（原 §5、§7）

| 平台 | 方案 | 何时需要 |
|---|---|---|
| Windows | PWA（浏览器直接用） | 立即：打印就是 `window.print()`，打印店与家用打印机都是 Windows |
| Linux / macOS | 同 PWA | 立即 |
| Android | Capacitor + Kotlin 原生插件 | P6，只为 UsageStats / 前台服务 / Widget / 专注遮罩 |
| Windows 进阶 | Tauri 2 | 可选、推迟，仅当需要本地文件系统 / 全局快捷键 / 托盘 / 后台采集 |
| 鸿蒙 | 不做 | NEXT 不兼容 APK、侧载受限、文档不成熟 |

Windows 不需要单独桌面 App：整理笔记、打印清单、看统计 PWA 全都能做，打印本就是浏览器最强领域。Tauri 唯一不可替代的是桌面端屏幕时长采集，属 P7 之后。**Windows 打包已停止，验收在网页 `http://127.0.0.1:4173/` 上进行**（见 `docs/DECISIONS/0002-packaging-experiment.md`）。

一套前端、多个壳：PWA 直跑（Windows/Linux/macOS/手机浏览器）、Capacitor 套壳（Android + Kotlin）、Tauri 套壳（可选 + Rust）；`core` / `ui` / `vision` / `plugins` 100% 共享，宿主层只有薄桥接。

技术栈：TS strict / React + Vite + Tailwind + shadcn 风格 / Dexie / CodeMirror6 + KaTeX / Excalidraw / Hono / Drizzle / Vitest + Playwright / Caddy + Compose。

私服（P7）：数据库用 SQLite（私服规模运维量≈0）；同步让客户端加密 vault blob，服务端不懂数据，实现量减半、隐私更强、schema 演化自由。

对象存储用预签名 URL，文件字节不经过服务器：

1. 客户端向服务器要上传地址（POST），服务器鉴权、查配额、校验类型/大小。
2. 服务器签发 5 分钟有效的 presigned PUT（限 `content-length`、key 带随机前缀）。
3. 客户端直接 PUT 到 MinIO/S3/R2/B2。
4. 客户端回报 `key + sha256`。
5. 服务器 HEAD 校验存在、大小、哈希一致才落库；下载用有效期更短的 presigned GET。

| 安全要点 | 原因 |
|---|---|
| 有效期分钟级 | 防止 URL 被转发后长期可用 |
| `content-length-range` | 防止绕过大小限制 |
| key 含随机前缀/UUID | 防止枚举 |
| 必须服务端 confirm（HEAD） | 否则客户端可伪报上传成功 |
| bucket 绝不公共读 | 防泄露 |
| sha256 去重 | 省空间，重复文件直接引用 |
| 签发接口限流 | 防止被当免费存储 |

私服服务器可以极小（几乎不承载流量）；R2 免费额度大、无出站费，或自家 NAS 的 MinIO。嫌 S3 重可用 nginx `X-Accel-Redirect` + 一次性 token，或本地盘 + HMAC 短链，原理相同。

## 11 数据安全与故障兜底（原 §15 摘要，细节指向 Phase-note/P1/data-safety.md）

数据只有一份时，三种丢法（浏览器驱逐 / 清缓存换设备 / 渲染崩溃白屏）各需一道不同的防线：
`navigator.storage.persist()`、备份提醒 + 一键导出、`ErrorBoundary` + 按页 `ScreenBoundary`、CI。
三种丢法、四道防线的对照表与验收见 `docs/Phase-note/P1/data-safety.md`。

原则：提醒挡在视线里但不挡路（「今天不再提醒」写本机），不弹窗、不强制、不拦操作。
边界兜不住事件处理器与异步回调里的异常，所以 `liveQuery` 只读规则仍必须遵守；新增页面必须包 `ScreenBoundary`（`docs/STANDARD.md` 第 7 条）。
无人值守自动备份没做：浏览器静默写盘只有 File System Access API，需授权且 Android WebView 支持不一致，跨设备备份本来就要服务端（P7）；「提醒 + 一键」已覆盖主要场景。详见 `docs/Phase-note/P1/data-safety.md`。
