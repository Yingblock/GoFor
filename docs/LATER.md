## 待删除：调试时钟

- [ ] **调试时钟（临时设施）—— 用户要求"后期提醒我删"** —— 宿主层
      `apps/web/src/clock.ts` 的 `appClock` 让"现在"可以前后拨（偏移存
      `localStorage`，刷新后仍生效），用于真机验证：课表「今天/明天有没有课」、
      打卡「今天能不能打、历史是否只读」、打印模板的「打印于」时间戳。
      为什么临时：真实"现在"被拨动后，与系统时间分叉的语义只该存在于调试期；
      且 `monotonic()` **绝不能偏移**（番茄钟已用时间按 monotonic 差值算），
      这层特殊处理没有长期价值。
      删除步骤（三步）：
      1. `apps/web/src/clock.ts` 里 `appClock` 改为直接转发 `systemClock`（或让宿主改回 import `systemClock`）；
      2. 删除 `apps/web/src/components/DebugPanel.tsx`；
      3. 删除 `apps/web/src/components/Sidebar.tsx` 里的 `<DebugPanel />` 挂载点。
      所有入口都标了 `TODO(debug-clock): 上线前删除`，`grep -rn "TODO(debug-clock)" apps/web/src` 可定位。

## P2 留下的简化

- [ ] **情绪日记的趋势图**：现在只有列表 + 标签，没有折线/热力图。
      做趋势要先定"心情到底怎么量化"（一天多条？按标签分？），不想随便画一条线。
- [ ] **四角定位块缺失/被裁时的退化**：现在会自动找四角，找不到再退回 `detectPageQuad`、最后手动四角；真机照片若把定位点裁掉，只能退回旧路径。
- [ ] **区块小定位点的真机精度**：1.2mm 小十字在真实照片/低端打印机上可能糊掉；扫描端按「两处都找到且缩放合理」才校正，否则该块退回页面坐标。需要在真实手机上量一轮再决定是否加大/换形状。
- [ ] **区块局部校正只做到平移 + 等比缩放**：没有块内单应，纸张明显起翘时仍有残差。
- [ ] **照片光照均衡**：背光/侧光会让 Otsu 阈值偏；现在靠"多拍一张"绕过去。
- [ ] **手写区仍然读不回来**：时间登记、`slots` 手写格需要 OCR；P2 用 `ratingGrid` 勾选格替代后者。
- [ ] **扫描端没做取景框**：现在是"选照片 / 抓一帧"，没有实时取景 + 自动对焦提示。
      手机上直接拍照体验更好，但需要 Capacitor 相机插件（P6）。

## 打包与打印的已知限制

- [ ] **系统打印框的纸型仍受打印机驱动控制**：代码只能把 `@page` 设对、在预览里要求选对应纸与 100% 缩放，
      无法强制纸盒。真正的"选 A5 就打 A5"要靠驱动配合。
- [ ] **用户自定义模板的行数不随纸张自动精简**（内置模板会）；自定义模板只改页尺寸与分页。
- [ ] **打印预览模态没有焦点陷阱**（有 Esc/返回/关闭），键盘用户可能 Tab 到背景——a11y 欠账。
- [ ] **情绪日记趋势图没有 tooltip/数值标签**，只能看形状。

## 数据安全：还没做的

- [ ] **无人值守的自动备份** —— 现在只有"提醒 + 一键导出 JSON"。
      真正的自动备份在浏览器里得靠 File System Access API（用户授权一次目录句柄后反复写），
      Chrome/Edge 可以，Android WebView 与部分内核不支持；跨设备备份本质是服务端功能，属于 P7。
      结论：P1 不做，等云存档阶段一起做。
- [ ] **备份文件加密** —— 导出的 JSON 是明文。本阶段不做合规/隐私处理（`docs/STANDARD.md` 规则 12），
      但自己存网盘时要知道这一点。
