# P2 · 纸的回流链路

> P1 的纸是单向的：程序打印、人写、数据留在纸上。P2 把纸上的勾选读回来。**不做通用 OCR**，先验比识别可靠。

## 为什么是坐标先验，不是 OCR

模板由本程序生成，**精确知道每个格子的坐标**，问题从「读懂手写勾选」降级为「已知矩形里有没有墨」。

| 难点 | 通用 OCR | 坐标先验 |
|---|---|---|
| 手写勾选符号千奇百怪 | 需要分类器，容易错 | 只判断有无墨迹，无歧义 |
| 纸张歪斜/透视 | 严重退化 | 定位块 + 透视变换 |
| 印刷文字干扰 | 会误识别 | 采样窗只覆盖手写区 |
| 中文手写 | 差 | 无关 |
| 离线 | 需模型 | 纯像素运算，可完全离线 |

- 不需要训练模型、不联网、不引入 OCR 体积。
- 准确率由纸张摆放与透视矫正决定，不由字迹决定。
- 失败是局部的：某一格读不准，用户勾一下就行。
- 代价：纸必须由本程序打印（坐标表要匹配），拍照要大致正对纸。

## 链路

```text
打印 → 固化坐标清单 SheetManifestRecord（键：模板@日期@纸张）+ 二维码
        二维码：gofor://fill?v=1&t=<模板>&d=<日期>&p=<纸张>（≥16mm）
拍照 → 四角定位（自动找定位块，手动四角兜底）→ warpQuad 单应矫正
     → 灰度 + Otsu 二值化
     → 二维码解码（全图，按四角外接矩形校验）；失败读页尾条码
     → 区块小点做局部平移 / 等比缩放校正
     → 逐格 inkRatio → 阈值判定（`DEFAULT_INK_THRESHOLD` 0.18；`config.inkThreshold` 默认 0.12 但尚未接入）
     → ScanBatch(pending) → 待确认列表 → 用户点「应用」才写库
```

三个刻意的选择：

1. **打印时固化清单**：回填时重新推导，中间改过作业顺序就会把勾记到别人头上，静默错数据比识别不出来严重得多。
2. **一律先进待确认**：识别结果永远不当成事实，用户确认后才写。
3. **局部坐标先验**：只读「已知矩形里的墨迹」，不推断文字内容。

## 读不了的手写区（明确不做）

- **时间登记**（`19:30` 这种手写时间）：需要数字识别，P2 不做；时间继续在界面上手动补。
- **`slots` 三手写小格**：同上。要回填数值改用 `ratingGrid` 区块，印成 1–5 的勾选格，墨迹检测就能读。
- **课表/表格里的文字**：只读「这一行有没有被划掉/勾过」，不读写了什么。

## 数据模型

| 表 | 作用 | 关键点 |
|---|---|---|
| `sheetManifests` | 打印时的坐标快照 | 键是 `模板@日期@纸张`；同一天换纸重打会各存一份 |
| `scanBatches` | 一次扫描的识别结果 | `status: pending → applied / discarded`；应用后留档可追溯 |
| `moodLogs` / `diaryEntries` / `toolboxRuns` / `checklists` / `checklistLogs` | 行为层 | 与扫描解耦：扫描只是**一种**写入口 |

## 失败与降级

- **纸上没有二维码 / 旧纸**（P2 之前打的）：允许手动选模板 + 日期；此时没有坐标快照，回填一律标「可能对不上，请逐条核对」，并按显式确认「按当前模板重建坐标」或重打。
- **没有摄像头**（桌面浏览器/无权限）：退化为「上传照片」，识别链路相同。
- **自动找角失败**：四角手动点；这是默认就提供的路径，不是应急。
- **识别不确定**：全部进待确认列表，不做自动应用。
- **采样到纸外**：矩形钳制在页内，面积为 0 时按「未勾选」处理。
