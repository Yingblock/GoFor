- 原表名是「初版使用反馈修复」「第二批反馈修复」「第三批反馈修复」「使用反馈第二批：可用性修复 + 设计系统」——
  有两个「第二批」。本表按实际修复时间排，`批次` 列沿用原名（可用性那批标「第二批（可用性）」）。
- 本表只记反馈与处理，不重复记交付块与验收证据：那些在 `docs/ROADMAP.md` 与
  `docs/Phase-note/P2/{print,paper-loop}.md`。

## 从这四批反馈里提炼的规则

- **界面状态不等于已落库**：先写数据再改 UI；e2e 要断言数据（新任务真的带标签），只数界面会漏。
- **一次性选择要进 config**：模板、纸张、打印参数只要在组件 `state` 里，纸面就读不到（改纸张仍按 A4 打就是这条）。
- **纸面数字必须端到端断言**：日期、作业行、自评块都要从「照片」解回纸面值，不能只看解析函数不抛错。
- **打印/采样是两份代码**：布局函数、采样窗、区块切分共享同一常量或函数，改一边必须改另一边。
- **降级要显式**：缺字段补空（`asTimetable`）、缺插件显示「未安装」，不要静默给 0 或判废。
